## Rule check per figure

Copy for each figure and tick before marking it final.

### F1

- [ ] Caption identifies the purpose or supported takeaway and explains how to read the figure
- [ ] Essential baseline, normalization, evidence status, and scope are clear
- [ ] Each caption number serves interpretation; repeated values remain available in readable labels, a table, or manuscript text
- [ ] Terms, abbreviations, baseline names, and metric boundaries match the claims terminology record
- [ ] Medians only, dispersion measure named, same measure as the rest of the set
- [ ] Units on every axis; log and truncated axes marked
- [ ] Readable in greyscale and at column width
- [ ] No decorative arrows; no font-size overrides
- [ ] Data file exists, README records how it was produced
- [ ] Every number in the caption matches the data file
- [ ] Hardware named by family, not part number
- [ ] Device, engine and format stated for any performance number

Use `.paperkit/memory/figure-captions.md` for caption choices. Record any
suggested removal or relocation of numerical detail and its verified
destination. Do not invent uncertainty or hide a losing case to shorten text.
